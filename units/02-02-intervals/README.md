## 1. 为什么需要一种新数据

一个标称 100Ω、容差 1% 的电阻，不是数值精确等于 100，而是实际值属于 `[99,101]`。区间表示的是**可能值集合的包围范围**，不是概率分布，也不是“最可能为中心值”的声明。

我们保存 `(lower . upper)`，只通过 `make-interval`、`lower-bound`、`upper-bound` 使用。构造器接受有序、有限实数端点，允许 `[a,a]`，拒绝倒置端点、NaN 和无穷。这里选择拒绝 `[3,2]`，不偷偷交换以掩盖调用错误。

对于 `X=[a,b]`、`Y=[c,d]`：

| 运算 | 结果 | 理由 |
| --- | --- | --- |
| `X+Y` | `[a+c,b+d]` | 和分别在两个下界、两个上界取极值 |
| `X-Y` | `[a-d,b-c]` | 最小值要减最大的减数 |
| `X×Y` | 四个端点乘积的最小值、最大值 | 乘法对各变量分别线性，矩形区域的极值在角上 |
| `X/Y` | `X×[1/d,1/c]`，前提是 `0∉Y` | 倒数在不跨零的每个区段单调递减 |

例如 `[-2,3]×[-4,5]` 的四个候选是 `8,-10,-12,15`，答案是 `[-12,15]`。不能只乘两个下界和两个上界，那会丢掉 `-12`。

## 2. 习题 2.10：除数包含零就拒绝

**题意概述**：修改区间除法，对跨零的除数报错。

正确条件是闭区间包含零：

```scheme
(<= (lower-bound y) 0 (upper-bound y))
```

不仅 `[-1,1]`，`[0,1]`、`[-1,0]`、`[0,0]` 都非法。仅检查“下界乘上界小于零”会漏掉端点等于零；仅让宿主 `/` 报错也会漏掉内部跨零但端点非零的情形。

```text
1 / [-1,1]
倒数不是 [1,-1]
负半段的倒数向 -∞ 延伸，正半段向 +∞ 延伸，并且 1/0 无定义
→ 当前单个有限闭区间模型不能表示，明确报错
```

负除数没有问题：`[2,4]/[-2,-1] = [2,4]×[-1,-1/2] = [-4,-1]`。

教材用 `1.0` 求倒数；本文件改用精确的 `1`，使精确输入的有理数端点保持精确。对于浮点输入，这个教学实现**没有有向舍入**，不能当作经过验证的工程区间库：浮点舍入可能让边界略向内缩。真实安全范围计算还需要向外舍入和溢出策略。这里用精确样例隔离“依赖丢失”问题，而非掺入舍入误差。

## 3. 用中心与容差看结果

```text
center([a,b]) = (a+b)/2
width([a,b])  = (b-a)/2
percent       = 100×width/|center|
make-center-percent(c,p) = [c-|c|p/100, c+|c|p/100]
```

百分比参数 `p` 用 `1` 表示 1%，不是用 `0.01`。`p` 必须非负；负中心仍可构造，例如 `-10±5%=[-10.5,-9.5]`。中心等于零时相对容差无定义，因此 `percent` 报错；零中心加百分比的构造只能生成 `[0,0]`，不能表达非零绝对宽度。这时应直接给端点。

## 4. 习题 2.14：代数等价，区间计算却不同

**题意概述**：验证并联电阻的两个等价公式结果不同；用较窄的 `A,B` 计算 `A/A`、`A/B` 等式，并从中心/百分比观察。

两种并联电阻公式为：

```text
par1(A,B) = AB/(A+B)
par2(A,B) = 1/(1/A + 1/B)
```

取 `A=100±1%=[99,101]`，`B=200±1%=[198,202]`，文件实际计算得到：

| 表达式 | 精确范围 | 中心（约） | 相对容差（约） |
| --- | --- | --- | --- |
| `A/A` | `[99/101,101/99]` | `1.00020002` | `1.99980002%` |
| `A/B` | `[99/202,101/198]` | `0.50010001` | `1.99980002%` |
| `par1` | `[6534/101,20402/297]` | `66.69333600` | `2.99920024%` |
| `par2` | `[66,202/3]` | `66.66666667` | `1%` |

先手算一次 `par1` 的完整传播：

```text
A×B   → [99×198,101×202] = [19602,20402]
A+B   → [297,303]
AB/(A+B) → [19602/303,20402/297]
          = [6534/101,20402/297]
```

这个下界把“分子两个电阻都取低值”和“分母两个电阻都取高值”拼在一起。实际同一对电阻不可能同时这样取值；区间系统没有保存它们的相关性。

`A/A` 暴露得更直接：对同一个非零实际数 `a`，`a/a=1`；但区间除法算的是两个**可独立取值**的参数，允许 `99/101` 和 `101/99`。即使两次传入的是同一个 pair，对象身份也不会自动变成代数依赖知识。反过来，两个不同电阻可能恰好范围相同，单靠端点相等也不能推断它们是同一不确定量。

`A/B` 的两个参数若独立，其四角极值可以真正达到，所以范围是合理的。把 `A` 缩成点区间 `[100,100]`，`A/A` 才由普通区间算术得到 `[1,1]`。

还可观察：`A-A=[-2,2]`，而代数化简后的同一量相减是 `[0,0]`；加减的宽度为输入宽度之和，不等于自动传播“抵消”。代码另检查了正负混合乘积、点区间和减法的端点规则。

### 为什么这个例子的 par2 更紧

对正电阻，`f(a,b)=ab/(a+b)` 对两个参数都单调递增，所以真实范围正是 `[f(99,198),f(101,202)]=[66,202/3]`，与 `par2` 一致。这个例子说明改写表达式可以保留更紧的范围，不说明“所有少重复表达式都一定最优”。一般表达式的相关性分析远比四则端点传播复杂；给变量加依赖标记、仿射算术或符号化简是更丰富的模型，不是本单元暗中实现的功能。

## 5. 运行与已回答回顾

```sh
racket units/02-02-intervals/solutions.rkt
```

程序先打印上述四行的精确端点与近似中心/百分比，最后输出 `02.02: all checks passed`。断言对精确端点比较，不把平台最后一位浮点显示作为标准；所有含零除数以及非法端点/容差均有捕获错误的测试。

- **代数恒等式错了吗？** 没错，是区间操作不保存“这两次出现来自同一个量”的约束。
- **更宽等于错误吗？** 若仍包住真实值，它是保守但不紧；浮点向内舍入则是另一类正确性风险。
- **负区间能作除数吗？** 能，只要整个闭区间不含零。
