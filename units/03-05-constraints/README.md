## 让同一关系双向工作

温度关系 `9C = 5(F-32)` 可以求 F，也可以求 C。普通函数通常固定参数与返回值；约束网络把**关系**作为模块，让当前已知信息决定计算方向。

连接器不是存一个数字就够了，它保存：

| 状态 | 用途 |
| --- | --- |
| value | 数值，只有 has-value? 为真时才有效 |
| informant | 最先提供当前值的用户或约束；也用来表示是否有值 |
| constraints | 连接在这里的约束过程列表 |

设置新值时，连接器记住来源，通知来源之外的约束 `I-have-a-value`；已有同值则忽略，异值则报矛盾。只有原来源才能撤回；撤回通知其余约束 `I-lost-my-value`。每个约束仅撤回**自己推出来的**结论，再用剩下的信息尝试重算。

这是同步通知，不用上一单元的仿真时间或事件议程。来源排除和“同值不重复传播”避免了最简单的通知来回循环，但它不是任意方程系统的完备求解器。

## 原始约束的规则

`adder(a,b,s)` 维护 `a+b=s`：知道任意两个便求第三个。`multiplier(a,b,p)` 维护 `ab=p`：通常知道任意两个可求第三个，但有零的例外。

- 已知 a=0，即使 b 未知也能得 p=0。
- 已知 a=0,p=0，不能除以零求 b；b 仍然未知。
- 已知 a=0,p=5，是矛盾，不是“无穷大的 b”。

代码先处理已知零因子，再处理乘法和除法。`constant` 给连接器提供固定值。构造约束时先连接各端口，有值的连接器会立即通知新约束，因此先接网络或先给部分已知值都能传播。

## 3.33：平均器必须保持双向性

**题意**：只用加法、乘法、常数约束，建立 `c=(a+b)/2`。

```text
a ─┐
   adder ─→ sum ←─ multiplier ─ c
b ─┘                  ↑
                 constant 2
```

代码创建内部连接器 `sum`、`two`，调用 `(adder a b sum)`、`(multiplier c two sum)`、`(constant 2 two)`。

正向追踪：用户设 a=10，信息还不够；用户设 b=20，加法器设 sum=30，乘法器由 sum=30,two=2 得 c=15。反向追踪必须先撤回旧输入：

1. 用户撤回 a。a 清来源；adder 撤回它提供的 sum。
2. sum 通知 multiplier；它撤回自己提供的 c，但不能撤回 constant 提供的 two。
3. b 仍为用户提供的20。用户设 c=25，multiplier 得 sum=50，adder 得 a=30。

这不是重新连线，也不是调用另一个“逆平均函数”。异值直接覆盖会留下错误推导，所以必须先撤回旧假设。

## 摄氏/华氏：一条完整信息路径

教材网络建立 `C*9=u`、`v*5=u`、`v+32=F`。

```text
用户 C=25 → u=225 → v=45 → F=77
撤回 C    → u未知 → v未知 → F未知（9、5、32仍在）
用户 F=212 → v=180 → u=900 → C=100
```

用户直接请求撤回一个由约束推导的 F 不生效；撤回能力必须匹配 informant。代码验证错误来源不改值，以及同一网络确实从两个方向得到温度结果。

## 3.35：平方不能只把乘法器的两个输入短接

**题意**：补全原始 `squarer(a,b)`，维护 `b=a²`，包括得知值、丢失值、分派和连接。

普通 `(multiplier a a b)` 可以从 a 求 b，却不能仅从 b 求 a：乘法器看见两个输入都未知，不知道它们其实是同一个未知量。专用平方器需要新知识：

```scheme
(if (has-value? b)
    (if (< (get-value b) 0)
        (error "Square less than zero" (get-value b))
        (set-value! a (sqrt (get-value b)) me))
    (if (has-value? a)
        (set-value! b (* (get-value a) (get-value a)) me)))
```

完整代码还实现：

- `I-have-a-value` 调用以上规则。
- `I-lost-my-value` 先对 a、b 都以 me 为来源请求撤回，再重新处理剩余信息。
- 其他消息报错。
- 将 me 连接到 a、b，返回 me 作为约束身份。

先设 a=-3 可以向前得 b=9。撤回 a 后 b 也失去推导；再设 b=16，反向得到 a=4。**反向选择主平方根**，不是自动列举 ±4；已知 b=0 得 a=0，b<0 在实数域报错。这个教材原始约束以 b 已知分支为先，不是支持所有多值解的代数系统：若两端预先都给定，它会按主根约定检查 a。要保留两个根需要集合值或搜索，第四章才讨论搜索机制。

## 限制不是隐藏功能

连接器只记一个来源，不维护全部独立证明。两个来源都宣称同值时，第二个不会成为备用证明；第一来源撤回后，是否重建要靠网络剩余信息。矛盾异常也**不提供事务回滚**：例如 b=-1 已被用户放进连接器，然后平方器才抛错；自检会显式撤回这个坏输入。不能把捕获异常误读为网络自动恢复原状。

这是局部传播、单值连接器模型，不会凭空解两个都未知的变量，也不保证任意循环网络终止。本文件不读外部输入，教学调用约定为实数值和非假来源；读取无值连接器主动报错，避免使用过期槽值。
